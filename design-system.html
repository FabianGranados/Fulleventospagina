✨ Animaciones y Transiciones

Duración Estándar

  • 🏃 Micro-interacciones: 150-300ms
  • ↔️ Transiciones: 200-300ms
  • 🔄 Complejas: hasta 400ms
  • ⚠️ Evitar: >500ms

Easing

  • 📈 Entrada: ease-out
  • 📉 Salida: ease-in
  • 🚫 Evitar: linear en UI
  • ✅ Preferir: transform/opacity

Transform Ejemplos

  • Hover: scale 1.02 + sombra
  • Click: scale 0.98
  • Card hover: translateY(-2px)
  • Fade in: opacity 0 → 1

📋 Pautas de Implementación

Responsive Design

  • Mobile: 1 columna, <640px
  • Tablet: 2 columnas, 640-1024px
  • Desktop: 3-4 columnas, >1024px

Accesibilidad

  • Contraste mínimo 4.5:1 para texto
  • Focus rings visibles en elementos interactivos
  • Botones mínimo 44×44px (touch target)
  • Alt text en imágenes significativas

Performance

  • Lazy load imágenes below-the-fold
  • WebP/AVIF para optimizar tamaño
  • Scroll infinito para feed de eventos
  • Skeleton screens mientras cargan datos
